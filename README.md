# 雲海の灯台守（くもうみのとうだいもり）

雲の上に浮かぶ小島で灯台守になり、灯台を灯して旅人を迎え、住民やふしぎな生きもの「ソラモチ」を育てながら、自分の好きな街をつくっていく、まったりした 3D 育成ゲームです。
**Android アプリ（APK）** としてスマホに入れて遊べます。ブラウザでも動きます。

## 遊び方の流れ

| 時間帯 | できること |
| --- | --- |
| 朝・昼 | 島を歩いて落ちているものを拾う、木をゆらす・岩をたたく、畑の世話、釣り、料理、建設 |
| 夕方 | 精霊のお願いを確認する、住民に差し入れをする |
| 夜（19〜5時） | 星集め、**灯台に燃料をくべて灯す** → 翌日、光に導かれて旅人や精霊がやってくる |

- 時間と季節は**現実の時計と連動**します（11月なら秋、夜は星空）。
- 1日に何回か遊ぶと、作物の成長・お店の売り上げ・訪問者が少しずつ変わります。

## 特徴

- **灯台を灯すと世界が広がる**：灯台レベルに上限はありません。レベルが上がるたびに、雲海から新しい浮島が浮かび上がり、虹の橋でつながります（草原・森・花・岩・なぎさ・霧・星屑・果樹）。
- **キャラクター**：
  - 種族 12 種、名前のある住民 46 人。それぞれ性格・好物・苦手・誕生日・口癖があります。
  - 季節の精霊が 24 体（春夏秋冬に 6 体ずつ）。
  - 全員と出会ったあとも、ランダムに生まれる旅人がずっと訪れ続けます。
- **食べものをあげて育てる**：
  - 住民のなかよしレベルは上限なしで上がります。4 レベルごとに家が増築され、3 レベルごとにレシピや設計図を教えてもらえます。
  - ソラモチは食べたものの系統（甘い・海の幸・星の味・花の香り）で大人の姿が 4 通りに変わり、どこまでも大きく育ちます。一定のレベルに達するとたまごが生まれ、数を増やせます。
- **建設と街づくり**：
  - 建物・建造物は 109 種類あります（住まい、お店、公共、自然、道・柵、空の建造物、家具・小物、畑）。
  - グリッドに自由に置いて、回転・移動・強化（上限なし）・片づけができます。
  - 家を建てると、旅人を誘って住んでもらえます。
  - お店は毎日売り上げを出します。
- **色ぬりカスタマイズ**：
  - 建物のパーツ（壁・屋根・窓・扉など）ごとに、好きな色と模様（しま・チェック・水玉・レンガ・木目・星柄・波・うろこ）をぬれます。
  - マイパレット、スポイト、「おまかせ」配色があります。
  - 灯台守の服とソラモチの色も変えられます。
- **ミニゲーム**：
  - 🎣 **雲釣り**：島のふちで遊べます。魚は 25 種類で、季節・時間・天気によって変わります。
  - 🍳 **料理リズム**：レシピは 18 品。うまく叩けると料理の品質（★）が上がります。
  - 🌠 **星集め**：夜だけ遊べます。夏はほたる、冬は雪の結晶が降ってきます。
  - 🌷 **花の交配パズル**：ステージは無限に続きます。見つけた花の色は、色ぬりに使えるようになります。
- **季節のおまつり**：花見、星祭り、お月見、収穫祭、雪灯り祭り、初日の出があります。

## 操作

| | スマホ | PC |
| --- | --- | --- |
| 移動 | 左下のスティック | WASD / 矢印キー |
| カメラ | 画面をドラッグ（回転）、ピンチ（ズーム） | ドラッグ／ホイール、Q・R（回転） |
| しらべる・話す | 右下の大きいボタン | E / スペース |
| 建設 | 右上の 🔨 | B |
| メニュー | 右上の 📖 | M |
| もどる | Android の戻るボタン | Esc |

建設モードでは、ドラッグで視点を移動し、地面をタップして置く場所を選びます。置いた建物をタップすると、色ぬり・移動・強化・片づけができます。

## 画質設定（アプリ内）

メニュー →「⚙️ 設定」で、いつでも切り替えられます。初回起動時は、端末の性能に合わせて自動で選ばれます。

- **プリセット**：省電力／標準／高画質
- **影**：なし／丸影／リアルタイム影（解像度 512／1024／2048）
- **描画解像度**：50〜100%
- **フレームレート**：30／60 FPS
- **アンチエイリアス**：オン／オフ
- **描画距離**
- **季節のエフェクト量**
- **雲海のゆらぎ**
- **同時に動かすキャラの数**
- **FPS 表示**

スマホが熱くなる、または重いときは「省電力」にするか、フレームレートを 30 にしてください。

## スマホ（Android）に入れる方法

APK は GitHub Actions が自動でビルドします（`.github/workflows/android.yml`）。

1. GitHub のリポジトリで **Actions → 「Android APK」** を開き、最新の実行結果から `kumoumi-toudaimori-apk` をダウンロードします（zip に APK が入っています）。
   - `v1.0.0` のようなタグを push すると、**Releases** に APK が直接添付されます。
   - `main` ブランチに push すると、`latest` というプレリリースに最新の APK が置かれます。スマホのブラウザで Releases ページを開くのがいちばん簡単です。
2. スマホで APK を開き、「提供元不明のアプリ」のインストールを許可してインストールします。
3. ホーム画面の「雲海の灯台守」から起動します。横画面・全画面で動きます。

> 現在の APK はデバッグ署名です。Google Play で公開する場合は、リリース用の鍵を作って GitHub Secrets に登録し、`assembleRelease` で署名する手順を追加してください。

### PWA として遊ぶ（予備の方法）

`npm run build` した `dist/` を GitHub Pages などに置いてブラウザで開き、「ホーム画面に追加」すると、オフラインで全画面のアプリのように遊べます。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173 で起動
npm run build      # 型チェック + 本番ビルド（dist/）
npm run cap:sync   # ビルドして android/ に反映
```

Android Studio で開く場合は、`npx cap open android` を実行します（Android SDK と JDK 21 が必要です）。

### 構成

- `src/core`：ゲームループ、時計（現実時間・季節・天気）、入力、画質設定、WebAudio の合成 BGM と効果音、セーブ（Capacitor Preferences と localStorage）
- `src/world`：浮島の生成、空、雲海、天気、灯台、橋
- `src/entities`：プレイヤー、住民、旅人、ソラモチ（パーツを組み合わせてキャラクターを生成）
- `src/build`：建設モード、建物の生成、色と模様のマテリアル
- `src/systems`：セーブデータ、なかよし度、ごはん、訪問者、畑、街の評価
- `src/minigames`：釣り、料理、星集め、花パズル
- `src/data`：アイテム、レシピ、種族、住民、精霊、建物カタログ、おまつり
- `android/`：Capacitor の Android プロジェクト

外部の画像・音声ファイルは使っていません。形はすべてローポリのプロシージャル生成で、音は WebAudio で合成しています。
